# PDF → DWG (Стр. 2, Узлы)

Исходный PDF векторный, текст в нём переведён в кривые. Скрипт:

1. берёт линии из PDF, склеивает отрезки в полилинии, восстанавливает дуги и окружности;
2. заливки (уплотнители, засечки размеров) переносит как сплошную штриховку (HATCH SOLID);
3. надписи (текст в кривых) заменяет настоящим текстом TEXT — стиль `GOST` (isocpeur.ttf, наклон 15°),
   высота 2,5 / 3,5 мм на листе (6,25 / 8,75 в модели);
4. рамку, штамп и обрезные метки не переносит.

Масштаб: модель в натуральную величину, мм (чертёж М 1:2,5; PDF был напечатан «по размеру листа»,
масштаб восстановлен по рамке формата A4 185×287 мм). Слои по толщине линий: `Линии 0.05` … `Линии 0.35`,
`Заливка`, `Текст`.

```
python3 convert.py исходный.pdf clusters.json выход.dxf seed_r2000.dxf
dxf2dwg -o выход.dwg выход.dxf          # LibreDWG (git master), формат AutoCAD 2000
```

`clusters.json` — группы глифов PDF, сопоставленные надписям; `seed_r2000.dxf` — пустой документ,
созданный LibreDWG (`dwgadd`), чтобы служебные handle соответствовали формату DWG.
